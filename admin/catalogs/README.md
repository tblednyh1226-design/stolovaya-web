# «Справочники» — изолированная версия

Вкладки **Номенклатура / Склады / Сотрудники**. Исходники реализованы в ветке
`stolovaya-staging-20261031`; в production не устанавливались.

Точка входа: `admin/catalogs/index.html`. В админке staging добавлена ссылка
«Справочники». Пока не настроено отдельное тестовое API, страница показывает
безопасный макет с заблокированными кнопками обновления — не обращается к
рабочему Supabase.

### Серверная часть

SQL и iiko Edge Function лежат в **закрытом** репозитории
`stolovaya-app/development/catalogs`. Справочники используют существующие
`dishes`, `points`, `employees`, `employee_roles` и `employee_point_access`.

Важное разделение:
- кнопка «Обновить из iiko» создаёт **предварительный пакет**;
- подтверждённый пакет номенклатуры обновляет лишь `catalog_iiko_products`,
  а не действующие `dishes`, чтобы не добавить сырьё как блюда;
- подтверждённый пакет складов обновляет `catalog_iiko_warehouses`,
  не изменяя реальные БК/БР/ПК/ПР и маршруты;
- сопоставление каждой новой позиции и назначения склада будет отдельной
  проверяемой операцией, которую согласуем с владельцем;
- уволенные сотрудники только помечаются на удаление с отзывом доступа.

### Вход

Личный вход по полному ФИО и паролю, задаваемому владельцем. Пароль хранится в
виде bcrypt-хеша. Первая учётная запись владельца назначается только из
изолированного серверного окружения с ролью service_role.

**Пока это реализовано для нового раздела; остальная старая админка ещё не
переключена с общего PIN.** Когда перейдём на общую авторизацию, старые способы
входа и идентификации должны быть окончательно закрыты.

Для подключения изолированного стенда предоставьте
`window.STOLOVAYA_CATALOGS_CONFIG` (пример — `config.example.js`). Не
подставляйте production Supabase URL; настройки iiko и secret keys остаются
только на сервере.

### Проверки

GitHub Actions: `Catalogs staging tests` проверяет синтаксис экрана, работу
валидации сотрудников и запрет ссылок на рабочий проект. SQL проверяется
отдельно на одноразовой PostgreSQL 17 в закрытом репозитории.
